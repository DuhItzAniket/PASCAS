## Milestone Versions

v0.1.0 shipped the whole plan as one release: calculator, expression
engine, CAS foundation, graphing + Desmos workspace, linear algebra /
statistics / units, web application with PWA, and production
packaging. The v0.2.0–v1.0.0 ladder below is kept for future
hardening cycles (command palette, matrix editor, GPU 3D, sharing
service) — see `docs/sdlc/PHASE-50.md` for the deferred list.

| Version | Milestone |
|---------|-----------|
| v0.1.0 | Scientific Calculator |
| v0.2.0 | Expression Engine |
